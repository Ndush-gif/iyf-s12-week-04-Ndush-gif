## Project
This week focused on core JavaScript concepts: variables, data types, operators, functions, control flow, loops, arrays, and object-based logic. The project contains small console exercises and mini programs built to practice the fundamentals.

## Included files
- `main.js`: JavaScript basics and exercises on strings, numbers, functions, conditionals, loops, and arrays
- `calculator.js`: basic calculator functions with operator handling and division-by-zero protection
- `gradetracker.js`: grade tracker that calculates averages, subject results, top student, and report cards
- `daily-challenges.js`: daily challenge tasks such as FizzBuzz, reversing strings, largest number detection, duplicates removal, and palindrome checks

## Run locally
1. Open the folder in a browser or VS Code.
2. Open `index.html`.
3. Check the browser console to view the JavaScript output.

## Lessons Learned
- I learned how to use variables, arithmetic operators, and functions to build simple JavaScript programs.

## Challenges Faced
- I encountered a calculator error in the console saying that `calculate` was not defined. I fixed this by checking the script structure and making sure the function was declared and loaded correctly.
- I also faced a problem with the `add` function not behaving as expected because of scope issues. I solved this by wrapping the logic in a block to keep it organized and avoid global conflicts.
- Debugging through console messages helped me understand how JavaScript executes functions and how small syntax or scope mistakes can stop a script.
